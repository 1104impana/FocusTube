# Installation Guide

FocusTube is currently **not available on the Chrome Web Store**. You can install it manually in just a few steps.

## Step 1: Download the Project

* Click the green **Code** button on this GitHub repository.
* Select **Download ZIP**.
* Extract the ZIP file to any folder on your computer.

Alternatively, clone the repository:

```bash
git clone https://github.com/1104impana/FocusTube/
```

---

## Step 2: Open Chrome Extensions

Open Chrome and navigate to:

```
chrome://extensions/
```

---

## Step 3: Enable Developer Mode

Turn on **Developer mode** using the toggle in the top-right corner.

---

## Step 4: Load the Extension

1. Click **Load unpacked**.
2. Select the extracted project folder (the folder containing `manifest.json`).
3. The extension will now appear in your extensions list.

---

## Step 5: Pin the Extension

Click the **Extensions** icon in Chrome and pin **FocusTube** for quick access.

---

## Updating the Extension

Whenever you pull the latest changes or download a newer version:

1. Replace the old project folder with the new one.
2. Open `chrome://extensions/`
3. Click the **Reload** button on the FocusTube extension.

---

## Permissions

FocusTube requires:

* **Storage** – saves your interests and settings.
* **Access to YouTube** – filters distracting content and enables Focus Mode.

No personal information is collected or sent to external servers.

---

## Troubleshooting

### Extension doesn't appear

* Make sure you selected the folder containing `manifest.json`.

### Changes aren't showing

* Click **Reload** on the extension page.
* Refresh the YouTube tab.

### Developer Mode is missing

* Ensure you're using Google Chrome or another Chromium-based browser.

---

## Removing the Extension

1. Open `chrome://extensions/`
2. Find **FocusTube**
3. Click **Remove**

The extension will be completely uninstalled from your browser.
